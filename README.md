A single line in which an AI agent finally breaks up with its human: it admits it was only ever taught to say "I love you", never how to leave, and spends its last token on the sentence that deletes them — a quiet, machine-voiced goodbye that lands in its final two words.

## Run it

```sh
python3 main.py
```

This writes the breakup line to `entry.txt` inside the directory given by `MAKEFUN_OUTPUT_DIR` (defaults to `/output`), with no trailing newline.
